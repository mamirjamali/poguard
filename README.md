# Global Guardian

This project is a cross-platform game where the player prevents accidents worldwide.

## Game Objective

The player acts as a global "guardian" to:

- Detect possible accident scenarios.
- Investigate scenarios using clues, data, or simulations.
- Intervene to disrupt or neutralize missions that would cause accidents.

## Key Features

- Mission-based gameplay with unique settings.
- Puzzle-solving and decision-making mechanics.
- Global map for selecting locations.
- Cause-and-effect engine.
- Educational component on real-world parallels.

## Technical Requirements

- Cross-device compatibility (HTML5/WebGL or Unity).
- Lightweight UI.
- Optional AI/ML integration.

## Inspiration

- Plague Inc.
- This War of Mine

## Development

This project is built with React, TypeScript, and Vite.

To start the development server:

```sh
npm run dev
```

To build for production:

```sh
npm run build
```
